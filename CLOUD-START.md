# Cloud-Start: sieben Sitzungen

Je Werkzeug eine Cloud-Sitzung (claude.ai/code → Neue Sitzung → Cloud → Repository `Tastyrob123/haus-ihrhaus-werkzeuge`), Modell Opus. Auftrag zum Einfügen:

## Der Giebel
```
Baue das Werkzeug «Der Giebel» fertig. Lies zuerst CLAUDE.md ganz, dann werkzeuge/giebel/AUFTRAG.md, und arbeite danach ohne Rückfragen bis «Der Giebel: fertig». Nur in werkzeuge/giebel/ schreiben, auf deinen eigenen Zweig pushen.
```
